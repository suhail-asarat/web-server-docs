# System Configuration

## Operating System

After checking the compatability list[^1] for the server, we have used `Ubuntu Server 22 LTS` operating system for this configuration. In order to configure the OS, we have followed official article from manufacturer's website[^2]. After selecting our OS, we downloaded the ISO file from the official website of Ubuntu[^3] then installed following the official tutorials[^4].

## Virtualmin

Virtualmin is a *Open Source Web Hosting Control Panel*[^5]. We have followed the *Automated Installation*[^6] instructions provided in the Virtualmin documentation.

Virtualmin installs Webmin[^7], *a web-based system administration tool for Unix-like servers and services*, and also necessary other services and packages.
